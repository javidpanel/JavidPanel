# Contributing to JavidPanel

JavidPanel is a proprietary source-available project. Public pull requests that alter protected Worker distribution code are not automatically licensed for reuse or redistribution.

## Good contributions

- documentation corrections;
- reproducible bug reports;
- compatibility findings;
- security reports through private vulnerability reporting;
- suggestions for user experience and installation documentation.

Do not publish credentials, Cloudflare tokens, Telegram bot tokens, secure paths, subscription links, private Worker builds, deobfuscated source, or user data in issues or pull requests.
