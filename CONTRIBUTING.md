# Contributing

JavidPanel is a proprietary source-available product. Public contributions are most useful for documentation corrections, reproducible compatibility reports and security reports.

Before opening an issue:

1. Remove tokens, passwords, subscription links and private identifiers.
2. Include the JavidPanel release version and client/runtime version where relevant.
3. Provide the smallest reproducible sequence of steps.
4. Use private vulnerability reporting for security-sensitive findings.

Do not publish deobfuscated or private owner source in issues or pull requests.
