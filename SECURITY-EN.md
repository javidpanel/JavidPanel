# JavidPanel Security

The security of your Cloudflare account, panel credentials and subscription links depends directly on how those items are handled.

## Use official resources only

- 🤖 Bot: `@javidpanelbot`
- 📢 Channel: `@javidpnl`
- 💻 GitHub: `github.com/JavidPanel/JavidPanel`

Do not install or update JavidPanel from unknown files or links.

## Cloudflare API Token

- Do **not** use a Global API Key for installation.
- Create the scoped token from the link provided by the official bot.
- Never send the token to another person, group or bot.
- If a token may have been exposed, revoke it in the Cloudflare Dashboard and create a new one.

## Panel password

- Use a strong and unique password.
- Never expose the password in a public message, issue or unredacted screenshot.
- A password manager is recommended.

## Subscription links and QR codes

A subscription URL should be treated as a credential. Share each user's link only with that user and never publish full links or QR codes in public channels, screenshots or GitHub issues.

## User management from the bot

Before performing an operation, verify that the correct panel and user are selected. Confirm destructive actions such as deletion only after checking the user details.

## Reporting a problem

Do not post tokens, passwords, subscription URLs or personal data in a public GitHub issue. Use the project's official support channel for sensitive cases.
