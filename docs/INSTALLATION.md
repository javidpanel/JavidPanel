# نصب JavidPanel برای کاربر نهایی

## روش رسمی

نسخه Production جاویدپنل فقط از مسیر Installer رسمی تلگرام نصب می‌شود. Deploy دستی فایل Worker روش پشتیبانی‌شده نیست.

### مرحله ۱ — شروع نصب

در ربات رسمی روی **نصب JavidPanel** بزنید. ربات ابتدا محدودیت تعداد پنل مجاز برای حساب تلگرام شما را بررسی می‌کند.

### مرحله ۲ — ساخت Cloudflare API Token

ربات یک لینک مستقیم به صفحه ساخت API Token کلادفلر می‌دهد که Permissionهای مورد نیاز Installer از قبل در آن تعریف شده‌اند. وارد حساب Cloudflare شوید، Permissionها را بازبینی کنید، روی **Create Token** بزنید و Token را کپی کنید.

Global API Key ارسال نکنید.

### مرحله ۳ — ارسال Token

Token را در همان گفتگوی ربات Paste کنید. ربات اعتبار Token را بررسی می‌کند. اگر چند Cloudflare Account در دسترس باشد، حساب موردنظر را انتخاب می‌کنید.

### مرحله ۴ — نصب خودکار

Installer به‌صورت خودکار:

1. یک KV Namespace اختصاصی می‌سازد؛
2. تنظیمات اولیه و Installation Marker را در KV ثبت می‌کند؛
3. رمز مدیریت قوی و تصادفی می‌سازد؛
4. Worker رسمی را از Release Manifest دریافت می‌کند؛
5. SHA-256 فایل Release را بررسی می‌کند؛
6. Worker را Deploy و KV را با binding `kv` متصل می‌کند؛
7. workers.dev را برای Worker فعال می‌کند؛
8. آدرس پنل و اطلاعات ورود را در تلگرام تحویل می‌دهد.

### مرحله ۵ — نگهداری اطلاعات

رمز مدیریت را در Password Manager ذخیره کنید. API Token کلادفلر در Installer به‌شکل رمزنگاری‌شده ذخیره می‌شود تا بروزرسانی‌های مجاز همان Worker انجام شوند. در صورت عدم نیاز به Auto Update می‌توانید آن را برای پنل غیرفعال و Token را از Cloudflare لغو کنید.
