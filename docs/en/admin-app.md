# JavidPanel Management App

The management panel can be installed on a phone and used as a standalone app.

## Install on mobile

1. Open the management panel address in your browser.
2. Sign in to the management panel.
3. Choose **Install app** or **Add to Home Screen**.
4. Launch JavidPanel from its new Home Screen icon.

## Main sections

- **Home:** panel, user and version overview
- **Panels:** update, check and manage each panel
- **Support:** view and answer user requests
- **Monitoring:** central checks, managed panels and reviewable events
- **More:** versions, bot settings, users and broadcasts

## Notifications

Open **Monitoring** and enable mobile notifications. After browser permission is granted, new support requests and important panel events can appear on that device.

Keep notification permission enabled for JavidPanel to receive alerts.
