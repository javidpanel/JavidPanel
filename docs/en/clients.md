# Clients and Subscription Links

After creating a user, obtain that user's subscription link and import it into a compatible client application.

## General process

1. Select the user in the panel or bot.
2. Copy the appropriate subscription link.
3. Open Add / Import Subscription in the client.
4. Paste and save the link.
5. Refresh the subscription.

## HAPP

If a HAPP-specific link is displayed for the user, import that output into the HAPP client.

Official website: [happ.info](https://happ.info/)

## QR codes

If a QR code is available, use the destination client's Scan QR function.

## Security note

Treat subscription links and QR codes as credentials. Never publish them in a public channel or an unredacted screenshot.
