# JavidPanel FAQ

## Where do I install JavidPanel?

Use the official `@javidpanelbot` Telegram bot.

## Do I need to download anything from GitHub to install JavidPanel?

No. Installation and updates are handled through the official bot.

## Should I keep the bot after installation?

Yes. Keeping the bot gives you access to My Panels and maintenance operations.

## Can I manage panel users from Telegram?

Yes. Select the panel from My Panels and open User Management.

## Does every user have a separate subscription link?

Yes. Each user should receive only their own subscription link.

## What should I do if a Cloudflare token was exposed?

Revoke it from the Cloudflare Dashboard and create a new scoped token.

## What are the official resources?

- `@javidpanelbot`
- `@javidpnl`
