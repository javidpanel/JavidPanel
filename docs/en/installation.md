# JavidPanel Installation

The official JavidPanel installation path is the **@javidpanelbot** Telegram bot.

## Requirements

- a verified Cloudflare account
- Telegram access
- a few minutes to complete the guided process

## 1. Open the bot

Open [@javidpanelbot](https://t.me/javidpanelbot) and choose **Install a new panel**.

## 2. Create an API Token

Use the button shown by the bot to open the Cloudflare API Token page. Follow the permissions prepared for the installation flow.

- Do not use a Global API Key.
- Copy the entire token.
- Send it only to the official bot.

## 3. Select an account

If the token can access more than one Cloudflare account, choose the account where JavidPanel should be installed.

## 4. Finish installation

The bot completes the installation and returns the panel access information. Store those details securely.

## After installation

Keep the bot available. **My Panels** provides quick access to maintenance and user-management operations such as:

- update
- reinstall
- clean reinstall
- delete
- manage panel users
