# Official JavidPanel Bot

Official bot: **[@javidpanelbot](https://t.me/javidpanelbot)**

The bot is not limited to first-time installation. It also provides quick access to the panels associated with your Telegram account.

## My Panels

Open **My Panels** and select the intended panel. Available actions are shown based on the panel's current state.

### Update

Moves the panel to the latest available public release.

### Reinstall

Re-deploys the same installation.

### Clean reinstall

Creates a fresh installation with new access details. Read the confirmation message before proceeding.

### Delete

Removes the selected panel after final confirmation.

### User management

Provides quick access to routine user operations from Telegram. See the [user management guide](user-management.md).

## Safety notes

- Verify the selected panel before every operation.
- Never send a Cloudflare token or panel password in a public chat.
- Use only `@javidpanelbot`.
