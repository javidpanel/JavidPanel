# Manage JavidPanel Users from Telegram

Routine user management can be handled directly from the official bot without opening the web panel every time.

## Open user management

1. Open [@javidpanelbot](https://t.me/javidpanelbot).
2. Choose **My Panels**.
3. Select the intended panel.
4. Open **User Management**.

## List users

The bot displays users associated with the selected panel. Choose a user to view the actions available for that account.

## Create a user

Choose **New User** and complete the guided steps. Depending on the active release, the bot can ask for information such as:

- user name
- expiration period
- traffic limit

A summary is shown before the user is created.

## View a user

The user screen shows the main details and available actions. If a subscription link or QR code is available, share it only with that user.

## Extend a user

Choose the user, select **Extend**, set the intended period and confirm the final summary.

## Delete a user

Choose the user and select **Delete**. Deletion is completed only after final confirmation.

> Always verify both the panel and the user name before confirming deletion.

## When to use the web panel

Use the web panel for more detailed settings or options that are not exposed by the bot. Telegram user management is intended for quick routine operations.

## Security

- Never publish subscription links.
- Share each QR code only with its intended user.
- Confirm destructive actions carefully.
- Use only `@javidpanelbot`.
