# اپ مدیریت جاویدپنل

پنل مدیریت را می‌توانید روی موبایل نصب کنید تا مانند یک اپ مستقل در دسترس باشد.

## نصب روی موبایل

1. نشانی پنل مدیریت را در مرورگر باز کنید.
2. وارد حساب مدیریت شوید.
3. گزینه «نصب اپ» یا «افزودن به صفحه اصلی» را انتخاب کنید.
4. پس از نصب، آیکون جاویدپنل از صفحه اصلی موبایل قابل اجرا است.

## بخش‌های اصلی

- **خانه:** نمای کلی کاربران، پنل‌ها و نسخه‌های فعال
- **پنل‌ها:** بروزرسانی، بررسی و مدیریت هر پنل
- **پشتیبانی:** مشاهده و پاسخ به درخواست‌های کاربران
- **پایش:** وضعیت کرون، ورکرها و رخدادهای نیازمند بررسی
- **بیشتر:** نسخه‌ها، تنظیمات ربات، کاربران و ارسال گروهی

## اعلان‌ها

در بخش «پایش»، اعلان موبایل را فعال کنید. پس از تأیید مرورگر، درخواست‌های پشتیبانی و رخدادهای مهم روی همان دستگاه نمایش داده می‌شوند.

برای دریافت درست اعلان‌ها، دسترسی اعلان مرورگر را برای جاویدپنل مسدود نکنید.
