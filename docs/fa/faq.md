# سؤالات متداول جاویدپنل

## نصب جاویدپنل از کجا انجام می‌شود؟

از ربات رسمی `@javidpanelbot`.

## آیا برای نصب باید `worker.js` گیت‌هاب را دانلود کنم؟

خیر. فایل `worker.js` موجود در این Repository فقط نمونه آموزشی است و برای نصب یا Deploy جاویدپنل استفاده نمی‌شود.

## آیا ربات را بعد از نصب می‌توانم حذف کنم؟

بهتر است ربات را نگه دارید، چون عملیات نگهداری و دسترسی سریع به «پنل‌های من» از همین مسیر انجام می‌شود.

## آیا می‌توانم کاربران پنل را از ربات مدیریت کنم؟

بله. پنل موردنظر را از «پنل‌های من» انتخاب کنید و وارد «مدیریت کاربران» شوید.

## برای هر کاربر لینک جداگانه وجود دارد؟

بله، هر کاربر باید لینک اشتراک مخصوص خودش را دریافت کند.

## اگر Token کلادفلیر را اشتباه فرستادم چه کنم؟

اگر احتمال می‌دهید Token در اختیار شخص یا سرویس دیگری قرار گرفته، آن را از Cloudflare Dashboard لغو کنید و Token جدید بسازید.
