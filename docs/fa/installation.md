# راهنمای نصب جاویدپنل

نصب رسمی جاویدپنل از طریق ربات **@javidpanelbot** انجام می‌شود.

## پیش‌نیازها

- یک حساب Cloudflare با ایمیل تأییدشده
- دسترسی به تلگرام
- چند دقیقه زمان برای تکمیل مراحل نصب

## ۱. ورود به ربات

ربات [@javidpanelbot](https://t.me/javidpanelbot) را باز کنید و **«نصب پنل جدید»** را انتخاب کنید.

## ۲. ساخت API Token

از دکمه‌ای که داخل ربات نمایش داده می‌شود، صفحه ساخت Cloudflare API Token را باز کنید. دسترسی‌های موردنیاز در همان مسیر مشخص می‌شوند.

- از Global API Key استفاده نکنید.
- Token را کامل کپی کنید.
- Token را فقط برای ربات رسمی ارسال کنید.

## ۳. انتخاب Account

اگر Token به بیش از یک Cloudflare Account دسترسی داشته باشد، ربات فهرست حساب‌ها را نمایش می‌دهد. حسابی را انتخاب کنید که می‌خواهید جاویدپنل روی آن راه‌اندازی شود.

## ۴. پایان نصب

ربات مراحل نصب را انجام می‌دهد و پس از موفقیت، اطلاعات ورود پنل را نمایش می‌دهد. این اطلاعات را در جای امن ذخیره کنید.

## بعد از نصب

ربات را نگه دارید. از بخش **«پنل‌های من»** برای عملیات نگهداری و مدیریت سریع استفاده می‌شود.

- بروزرسانی
- نصب دوباره
- نصب تمیز
- حذف
- مدیریت کاربران پنل
