# راهنمای ربات رسمی جاویدپنل

ربات رسمی: **[@javidpanelbot](https://t.me/javidpanelbot)**

ربات فقط برای نصب اولیه نیست و بعد از نصب نیز مرکز دسترسی سریع به پنل‌های شماست.

## پنل‌های من

از منوی **«پنل‌های من»**، پنل موردنظر را انتخاب کنید. بر اساس وضعیت پنل، عملیات قابل استفاده نمایش داده می‌شوند.

### بروزرسانی

پنل را به نسخه عمومی جدید منتقل می‌کند.

### نصب دوباره

همان نصب را دوباره راه‌اندازی می‌کند و برای زمانی مناسب است که می‌خواهید خود پنل مجدداً Deploy شود.

### نصب تمیز

یک نصب تازه ایجاد می‌کند. اطلاعات ورود جدید خواهد بود و باید قبل از تأیید، پیام هشدار ربات را مطالعه کنید.

### حذف

پنل انتخاب‌شده را پس از تأیید نهایی حذف می‌کند.

### مدیریت کاربران

امکان انجام کارهای روزمره کاربران از داخل تلگرام را فراهم می‌کند. برای جزئیات، [راهنمای مدیریت کاربران](user-management.md) را ببینید.

## نکات مهم

- قبل از هر عملیات، نام/شناسه پنل را کنترل کنید.
- Token یا رمز پنل را در گفتگوهای عمومی ارسال نکنید.
- فقط از ربات `@javidpanelbot` استفاده کنید.
